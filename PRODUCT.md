# Product

## Register

product

## Users and purpose

Consola is a desktop command center for developers working with AI coding agents. Workspaces organize repositories, sessions, and issue-tracker work. Users switch between ongoing tasks while keeping their terminals available.

## Interaction direction

The workspace navigation follows the user's Slack references: a dedicated icon rail, a separate Home and Inbox column, and a menu named for the selected workspace. Keep the icons and tooltips compact. Workspace position determines the Command-number shortcut.

## Design principles

- Keep frequent actions immediate and predictable.
- Preserve workspace identity and running sessions when organizing navigation.
- Show attention markers only for prompts awaiting the user.
- Use subtle, purposeful feedback for direct manipulation.
- Respect the existing theme and the user's preference for uncluttered icons.

## Anti-references

Avoid oversized hover menus, extra backgrounds behind uploaded artwork, enclosing selection frames that compete with logo shapes, and persistent status circles when nothing needs attention.

## Accessibility

Maintain keyboard access, accessible workspace names and shortcut hints, visible focus, screen-reader feedback for reordering, and reduced-motion alternatives.
